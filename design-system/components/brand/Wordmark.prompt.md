One-line: the Sokndall name as a wordmark — use it wherever a logo would sit, because this system has no logo file.

```jsx
<Wordmark size={24} />
<Wordmark size={20} tone="inverse" />   {/* dark footer */}
```

Tones: `ink` (default, near-black), `inverse` (white), `accent` (forest green). Always uppercase, 0.06em tracking. Never add a drawn glyph beside it.
